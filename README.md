# 🍔 Burger Palace

Fresh Burgers. Amazing Taste. Fast Delivery.

Welcome to Burger Palace, a modern and visually appealing burger restaurant website designed to showcase delicious meals, highlight restaurant services, and provide customers with a simple way to explore the menu and build their orders.


## 📸 About the Project

Burger Palace is a restaurant landing page focused on delivering an engaging online food experience. Visitors can discover the restaurant's offerings, explore different burger options, select quantities, and view their order summary.

The website features an attractive layout, food imagery, clear pricing in Kenyan shillings (KSh), and convenient navigation.

## ✨ Features

Responsive Navigation — Easily navigate between Home, Services, Our Menu, About, and Contact sections.

Hero Section — A welcoming introduction with an engaging headline and an Order Now call to action.

Restaurant Services — Highlights quality burgers, fast delivery, and delicious meals.

Interactive Food Menu — Explore a variety of meals with images, descriptions, and prices.

Quantity Selection — Increase or decrease the quantity of menu items.

Order Summary — Review selected items and the total order price.

Featured Burger Section — Showcases the signature Double Decker burger.

Newsletter Subscription Section — Provides an interface for visitors to subscribe to updates and special offers.

Contact Navigation — Offers a convenient way for visitors to find contact information.

GitHub Pages Hosting — Publicly accessible through a live website link.

## 🚀 Getting Started

Follow these steps to run the project locally.

Prerequisites

You will need:

A modern web browser such as Chrome, Firefox, or Edge.

Git installed on your computer.

A code editor such as Visual Studio Code.

## Installation

1. Clone the repository

   `git clone https://github.com/BJomo001/Burger-Palace.git`


2. Navigate to the project directory

   `cd Burger-Palace`


3. Open the project

   Open the project folder in your preferred code editor.

4. Run the website

   Open the index.html file in your browser, or use the Live Server extension in Visual Studio Code for local development.

No package installation is required for a static HTML, CSS, and JavaScript project.
